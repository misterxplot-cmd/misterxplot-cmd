# 💼 Практический опыт в ML

<details>
<summary>
  <b>🛍 hm-repeat-purchase-ml</b> — Прогнозирование повторных покупок клиентов H&M
</summary>

<br>

Самостоятельная ML-разработка · Октябрь 2026.

Прогноз покупки в следующие 30 дней по истории клиента за 90 дней.
Полный эксперимент: **31,8 млн товарных записей**, **1,36 млн клиентов**,
**10,7 млн клиентских срезов**.

### Что реализовано

- PostgreSQL в Docker, загрузка и аудит полного набора данных.
- SQL-агрегация, проверки кардинальности JOIN и клиентская витрина.
- Три основных признака: частота, давность и средняя сумма покупок
  в исходной шкале `price`.
- Сравнение LogisticRegression и CatBoost с recency baseline
  на трёх временных срезах.
- Калибровка вероятностей, финальный тест и пакетная выгрузка прогнозов.
- CLI, 43 теста и автоматические проверки в GitHub Actions.

### Результаты

Финальный тест — **539 884 клиента**.
Выбранная модель — **CatBoost с тремя признаками**.

| Метрика | Recency baseline | CatBoost |
|---|---:|---:|
| ROC-AUC | 0,6143 | 0,6876 |
| Precision@5% | 49,00% | **75,09%** |
| Lift@5% | 1,564 | **2,396** |

Верхние 5% списка — 26 995 клиентов.
Прирост Precision@5% относительно baseline — **26,09 п.п.**

### Stack

`Python` `SQL` `PostgreSQL` `pandas` `NumPy` `scikit-learn`
`CatBoost` `Docker` `pytest` `GitHub Actions`
