### 🚀 Ключевые проекты

📈 **[dutch-auction](https://github.com/MISTERXPlot/dutch-auction)**

- **Суть:** учебная симуляция голландского аукциона на Python.
- **Что сделано:** реализовал 5 различных торговых стратегий, алгоритмы оценки справедливой стоимости и визуализацию графиков изменения цен.

---

🛡️ **[transaction-risk-api](https://github.com/MISTERXPlot/transaction-risk-api)**

- **Суть:** сервис на FastAPI для инференса моделей оценки риска транзакций.
- **Что сделано:** настроил строгую валидацию входных данных, реализовал одиночные и пакетные прогнозы, развернул демо-модель и покрыл сервис тестами.

---

💡 **[numba-session-features](https://github.com/MISTERXPlot/numba-session-features)**

- **Суть:** высокопроизводительный расчёт признаков пользовательских сессий.
- **Что сделано:** оптимизировал вычисления с использованием Python и Numba (JIT-компиляция), провёл бенчмарк скорости и реализовал классификацию на scikit-learn с использованием синтетических данных.

---

📊 **[transaction-risk-ml](https://github.com/MISTERXPlot/transaction-risk-ml)**

- **Суть:** проект по исследованию и классификации рисков финансовых транзакций.
- **Что сделано:** провёл полный пайплайн анализа данных на pandas и scikit-learn, реализовал Feature Engineering и настроил валидацию для проверки Data Leakage.
